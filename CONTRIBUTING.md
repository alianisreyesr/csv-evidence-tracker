# Contributing

Thanks for helping improve this portfolio project.

1. Open an issue describing the problem or proposed change.
2. Create a focused branch from `main`.
3. Follow the README setup and verification commands.
4. Add or update tests and traceability documentation for behavioral changes.
5. Open a pull request explaining the validation-evidence impact and verification performed.

Use synthetic records only. Do not contribute proprietary, personal, patient, employer, production, or regulated data. Report vulnerabilities through `SECURITY.md`.

# Portfolio Safety and Intended Use

## Intended use

This repository is a portfolio-safe prototype that demonstrates software engineering, Computer System Validation (CSV), and quality-systems design practices.

## Data boundary

All examples, seed data, screenshots, and test fixtures must be synthetic, fictional, or otherwise safe for public sharing. Do not commit:

- Personal or patient information
- Credentials, API keys, tokens, or connection strings
- Proprietary company data or internal documentation
- Production validation records, test evidence, deviations, CAPAs, or quality records
- Information that could identify a regulated site, product, supplier, or system

## Regulatory boundary

The project may illustrate concepts related to requirements traceability, IQ/OQ/PQ execution, audit trails, GAMP 5, ALCOA+, and 21 CFR Part 11. It is not a validated GxP system, does not establish compliance, and must not be used for production regulated decision-making.

## Review expectations

Any change that affects requirements, test evidence, audit trails, records, or reporting should be reviewed for traceability, reproducibility, data integrity, and appropriate human oversight.

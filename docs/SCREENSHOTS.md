# Screenshots (portfolio)

Add 3–5 screenshots here (or under `docs/images/`) and reference them from the README. Suggested captures:

1. **Dashboard** — summary cards / overall status
2. **RTM** — requirements-to-test traceability view
3. **Test Queue / Executions** — IQ/OQ/PQ status
4. **Deviations** — list or detail with risk context
5. **Audit Log** — reviewable trail

## How to add them

```bash
# Example structure
mkdir -p docs/images
# Place PNGs/JPGs, then in README:
# ![Dashboard](docs/images/dashboard.png)
```

Keep images small (< 500 KB each) and free of any real/regulated data. Use only the synthetic demo data that ships with the project.
